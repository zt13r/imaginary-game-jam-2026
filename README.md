# Imaginary Game Jam 2026
Entry for the [Imaginary Game Jam 2026](https://itch.io/jam/imaginary-game-jam-2026)

The main theme: **Magical Research**  
My individual twist: **Failure**


## Gameplay loop in case I forget
1. Player creates a magic circle according to the rules in the Rulebook.
2. The magic spell must be effective enough to complete the practical exam.

## Magic System
- Very much like programming. If-else statements that dictate the flow of mana in the magic circle.
- There are (hopefully) many sigils to choose from for the spells:
  - Cast Sigils: magic that applies an effect to the target.
  - Condition Sigils: magic that confirms a condition before branching to another sigil (if-else).
